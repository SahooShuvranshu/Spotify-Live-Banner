Spotify Live Banner

Personalize your profile with a professional, lightweight engine that generates high-fidelity dynamic SVG banners to showcase your real-time listening activity on GitHub and beyond.

Why use this?

Traditional "Now Playing" widgets often rely on complex iframes or slow-loading scripts. Our engine generates a pure SVG image server-side, ensuring lightning-fast loads and 100% compatibility with GitHub's Markdown renderer.

Supported Platforms

Seamlessly connects with your Spotify or Last.fm account. It automatically handles token refreshes and player state synchronization.

Technical Architecture

Dynamic SVG Engine

The widget is rendered using a custom Python backend that injects live music data into optimized SVG templates, allowing for rich CSS animations inside an image format.

Secure Integration

Your credentials (API keys and tokens) are stored safely as environment variables. We never share or log your private account data.

Smart Caching

To ensure high performance and respect API rate limits, we use an intelligent in-memory caching system for album artwork and scan codes.

Want to make your own widget?

The Spotify Live Banner is fully open-source and designed to be self-hosted. By deploying your own instance, you have 100% control over your data and can customize the code to fit your exact needs.

1. Clone & Setup

Fork the repository on GitHub and set up your Spotify/Last.fm API credentials as environment variables. We provide a detailed guide in the README.md.

2. One-Click Deploy

Support for **Vercel**, **Railway**, and **Render** is built-in. Simply connect your repository and your personalized banner engine will be live in minutes.

API Customization

Tailor the banner to match your profile's aesthetic by appending these parameters to your URL.

Parameter Valid Options Default Description
recently_playing true, false false Toggle whether to show your last played track when inactive.
adaptive true, false false Extract dominant color from artwork for EQ and Glass themes.
blur true, false false Apply a blurred artwork background (Neutral when inactive).
theme light, dark, glass light Adjusts the background and text contrast.
spin true, false false Enables a rotating record animation for the cover art.
eq_color Hex (e.g. FF0000), rainbow 1DB954 Sets the color of the animated equalizer bars.
scan true, false false Displays a scannable Spotify code (Requires Premium).
